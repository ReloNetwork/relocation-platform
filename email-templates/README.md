## 🚀 How to Send

1. **Copy HTML content** from the desired template file
2. **Go to** `http://localhost:3000/admin/send-email`
3. **Login** with: `admin` / `ReloSecure2024!Network`
4. **Paste HTML** into the email body field
5. **Add recipient email** and subject line
6. **Send!**
